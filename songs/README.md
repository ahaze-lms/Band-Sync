# Bundled songs

Public-domain melodies, transcribed by hand. The compositions themselves
are unambiguously public domain; the arrangements here are dedicated to
the public domain (CC0). Safe to bundle, distribute, modify, and use
commercially.

Generated by [`tools/build-songs.mjs`](../tools/build-songs.mjs) — edit
the note arrays there and re-run `node tools/build-songs.mjs` to
regenerate.

| File | Composition | Year | BPM |
|---|---|---|---|
| `twinkle-twinkle.mid` | "Ah! vous dirai-je, maman" (French folk melody) | 1761 | 100 |
| `mary-had-a-little-lamb.mid` | Lowell Mason | 1830 | 96 |
| `ode-to-joy.mid` | Beethoven, 9th Symphony theme | 1824 | 112 |
| `frere-jacques.mid` | Traditional French round | 18th c. | 108 |
| `saints-go-marching-in.mid` | Traditional American spiritual | early 1900s | 120 |

All files are format-1 SMF, 480 PPQ, single piano track on channel 1
named "Piano" (so the game's role-guesser auto-assigns them).
