BUILD YOUR OWN SONGS

Record each instrument part one track at a time, tighten up the timing, edit notes in a piano roll, then combine everything into a playable BandSync song.

MVP FEATURES
  • Set BPM by typing or tapping tap-tempo
  • Record MIDI input live with a 4-beat count-in
  • One-click quantize — snap notes to the 16th-note grid
  • Piano roll editor — view, move, add, and delete notes
  • Up to 4 tracks — piano, drums, bass, guitar — with mute & solo
  • Playback all tracks together with the existing audio engine
  • Export as .mid and add to your game library
