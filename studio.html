IN DESIGN
WHAT IT DOES
OVERVIEW

BUILD YOUR OWN SONGS

Record each instrument part one track at a time, tighten up the timing with quantization, edit notes in a piano roll, then combine everything into a playable BandSync song — and share it with friends or the world.

WORKFLOW

HOW IT WORKS

  • Set BPM by typing or tap-tempo
  • Arm a track, hit Record — 4-beat count-in plays
  • Perform your part on any MIDI instrument
  • Quantize: snap notes to the 16th-note grid
  • Edit in the piano roll — move, add, delete notes
  • Repeat for each of the 4 tracks
  • Mix, then publish to the game library
INSTRUMENTS
INSTRUMENT STATUS PIANO ROLL VIEW
Piano WORKING MIDI pitch — 88 keys on left margin, notes as bars (width = duration)
Drums WORKING Named drum lanes — KICK, SNARE, HH_CLOSED… Hit markers, no duration
Bass v1.5 4 strings × frets — fretboard layout, notes as bars per string
Guitar v2.0 6 strings × frets + chord diagram overlay
Vocals v2.5 Pitch contour with lyric syllable labels inside each note bar
COLLABORATION & SHARING
COLLABORATE

INVITE FRIENDS TO CONTRIBUTE

Assign any of the 4 track slots to a specific friend. They open the song, hear your tracks playing back, and record their part. You keep ownership; they own their track.

  • Async (v1) — friend records when they're ready
  • Real-time (v2) — both editing live, one track each
SHARING

TWO SEPARATE ACTIONS

  • Invite to Collaborate — specific friend, edit access to their assigned track
  • Publish to Library — friends-only or public, play-only access

Public songs appear in Browse / Discover. Any public song can be remixed — forked into your own project with the original attribution preserved.

MVP vs LATER
BUILDING FIRST

MVP

  • BPM input + tap tempo
  • Piano + drum track recording
  • One-click 16th-note quantize
  • Piano roll — move, add, delete notes
  • Instrument-specific view (keys vs drum lanes)
  • 4 tracks, mute / solo, playback
  • Async collaboration + async track assignment
  • Publish private / friends / public
  • Export as .mid
COMING LATER

V2+

  • Quantize strength slider + multiple grid sizes
  • Note resize, rubber-band select, copy / paste
  • Piano roll zoom (X and Y)
  • Real-time collaboration
  • Browse / Discover public library + remix
  • AI Generate — describe a song, get a full 4-track starting point
  • AI Assist — select a region, ask Claude to improve it
  • Bass, guitar, vocal instrument views
  • Undo / redo, punch-in recording
